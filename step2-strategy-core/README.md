# 第 2 步：策略核心（估值温度表 + 回测引擎）

## 目标

定义并固化「因子 → 温度分 → 定投倍数」的完整规则，这是整个智能体的灵魂。

## 因子池（初步）

- 估值类：PE/PB 历史分位、股债性价比 ERP、股息率分位
- 趋势类：价格相对 250 日均线偏离、近 N 月回撤、波动率
- 情绪类：换手率/成交额分位、北向资金、新发基金规模
- 宏观类：10Y 国债收益率、PMI、社融、CPI/PPI

## 估值指标映射：不同标的用不同尺子（重要规则）

温度表默认用 PE(TTM) 历史分位，**只对宽基成立**。纳入行业指数或多类标的后，
必须按标的类型切换估值指标，否则会踩「低 PE 陷阱」。

| 标的类型 | 主用指标 | 辅助指标 | 说明 |
|---|---|---|---|
| 宽基（沪深300/中证500 等） | PE(TTM) 历史分位 | PB、股债性价比 ERP | 盈利波动被分散抵消，PE 分位可靠 |
| 周期行业（钢铁/煤炭/券商/有色/化工） | **PB 历史分位** | 盈利周期位置 | PE 随盈利周期反向失真 |
| 成长行业（科技/医药/新能源） | **PEG**（PE÷增速） | 营收增速、渗透率 | PE 高≠贵，看增速 |
| 金融（银行/保险） | **PB** | ROE、不良率 | 资产质量优先 |
| 红利/公用事业 | 股息率分位 | 股息率绝对值 | 赚分红，看股息率贵不贵 |

### 术语约定

- 低估 = undervalued（价格 < 内在价值）
- 中位档 = **合理估值 / 公允价值（fair value）**，即估值中枢附近
- 高估 = overvalued（价格 > 内在价值）

### 为什么行业 PE 分位会失真（低 PE 陷阱）

PE = 价格 ÷ 盈利，分母（盈利）剧烈波动：
- 盈利周期底部 → 盈利低 → PE 被动抬高 → 看似"高估"，实为低估买点
- 盈利周期顶部 → 盈利高 → PE 被动压低 → 看似"低估"，实为高估陷阱
- 结果：周期行业常"越跌 PE 越高、越涨 PE 越低"，用 PE 分位方向会反掉

## 温度表（草案，待回测标定）

| 温度 | 状态 | 买入动作 |
|---|---|---|
| <20 | 极低估 | 2.0x / 周期缩到 3 天 |
| 20~40 | 偏低 | 1.5x / 每周 |
| 40~60 | 中性 | 1.0x / 基准 |
| 60~80 | 偏高 | 0.5x / 周期拉长 |
| >80 | 高估 | 停买，只考虑卖 |

## 卖出端（分批止盈，需提前定死）

- 温度高位 + 达到目标收益 → 分批减仓
- 温度 > 90 → 强制只减不买
