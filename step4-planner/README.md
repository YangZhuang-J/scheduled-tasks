# 第 4 步：定投沙盘（Streamlit）

**目的**：直观感受「档位结构 + 金额 + 频率」不同组合下，历史上这条定投曲线长什么样、赚多少、最深亏多少。

## 启动

```bash
cd step4-planner
~/fund-dca-venv/bin/python -m streamlit run app.py
```

浏览器打开 http://localhost:8501

## 页面结构

```
顶部：标的 + 时间范围
主区：
  ① 价格走势 · 买卖点 · 估值分位色带（主图）
  ② 持仓市值 vs 累计投入（可多配置对比）
  ③ 持仓收益率 + 止盈阶梯线（可多配置对比）
  ④ 6 个关键指标：累计投入/平均月投入/最终市值/总收益率/最大浮亏/买卖次数
  ⑤ 配置对比表

侧边栏：
  · 标的、起止日期
  · 档位预设（3档/5档）→ 表格可改（分位区间 + 频率 + 金额）
  · 止盈设置（闸门分位 + 三档盈利阶梯）
  · 财务校验（月收入/支出/现金/收入下降）
```

## 支持的标的（13 个，已预热缓存）

**宽基**：沪深300、中证500、中证1000、中证800、中证100、上证50、上证180、深证100、创业板指、创业板50

**红利**：上证红利、深证红利、中证红利

> 数据要求：乐咕乐股 PE 历史 ≥ 6 年（否则 5 年滚动分位无法计算）+ 新浪有日线价格。
> 不支持的：中证A50/A500（PE 历史仅 2~3 年）、科创50（仅 6.4 年，分位样本不足）、
> 以及 9xxxx/93xxxx 系列（新浪无价格源，如中证科技、中证红利质量、中证半导）。

## 导出到推送配置（累加模式）

每次导出只处理**当前标的**，但会**读取现有 settings.json 并合并**，不会冲掉其他标的：

```
沙盘调沪深300 → ➕ 写入推送配置  → settings.json: [沪深300]
切到中证500   → ➕ 写入推送配置  → settings.json: [沪深300, 中证500]
```

- `start_date` 首次导出设为当天，后续导出**保持不变**
- 支持 ➖ 从配置中移除当前标的
- 导出前显示负担确认（月均投入 / 结余占比 / 最大浮亏）

## 关键设计

### 定投频率 vs 预算口径（两个不同概念）

- **定投频率**：每个档位独立设置（每日/每周/每双周/每月）—— 低估档可以每日买，正常档每周买
- **平均月投入**：由系统按**实际回测数据**算出，让用户看清「我这个配置，实际每月花多少钱」

### 档位划分的业内依据

| 平台 | 划分 |
|---|---|
| 且慢 | 30℃ 低估 / 70℃ 高估（3 档） |
| 蛋卷、雪球 | <30% 低估 / 30~70% 正常 / >70% 高估（3 档） |
| 天天基金 | 0-15 / 15-35 / 35-70 / 70-85 / 85-100（**5 档非等分**） |
| 橙财（上证） | 20/40/60/80 等分（**5 档等分**） |
| 61 指数估值表 | 历史最低 / 20%分位 / 50%均值 / 80%分位 / 历史最高 |

本工具提供 4 个预设：3档20/80（我们标定）、3档30/70（业内通用）、5档20/40/60/80（等分）、5档15/35/70/85（天天基金式）。

## 实测示例（沪深300，2015-2026）

| 配置 | 累计投入 | 市值 | 总收益率 |
|---|---|---|---|
| 3档 300/100/0（周） | 54,900 | 67,812 | **23.5%** |
| 5档 月投 100/80/50/10/0 | 5,360 | 6,440 | 20.2% |
| 无脑定投 每周100 | 60,700 | 69,320 | **14.2%** |

估值定投明显优于无脑定投，且投入更少。
