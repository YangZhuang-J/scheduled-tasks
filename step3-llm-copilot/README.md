# 第 3 步：LLM 副驾（策略解释 + 资讯整合）

## 目标

让决策结果「讲人话」，并整合非结构化资讯（新闻、政策、事件）。
**注意：LLM 只解释，不做买卖决策。**

## 定位

- 规则引擎 = 仪表盘 + 自动变速箱（读估值、换挡）
- LLM = 副驾驶讲解员（"现在 PE 在 15% 分位，比历史 85% 时间便宜，所以这次加倍"）

## 输入

- 规则引擎输出的 JSON 决策（买/卖/持有 + 倍数 + 理由）
- 当日因子快照
- 财经新闻/宏观资讯（东财快讯、金十、国内财经媒体等）

## 输出

- 每日自然语言策略报告
- 回答用户追问（"为什么今天加倍？"）

## 参考架构

- virattt/ai-hedge-fund（多 agent 分工，但它是美股/交易，仅借鉴架构）
- 上轮调研的 akfund-mcp 已有新闻/宏观工具可复用

## 产物

- prompt 模板（策略解释、资讯摘要）
- 报告生成脚本
- 接入方式（可选：接入现有 AI 助手对话）
