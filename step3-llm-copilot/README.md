# 第 3 步：LLM 副驾 —— 结论：只做「说人话」，不做新闻

## 最终决策

| 模块 | 结论 | 原因 |
|---|---|---|
| **A. 说人话** | ✅ **已实现**（`humanize.py`） | 价值高：降低理解成本、增强坚持、零成本零故障 |
| **B. 新闻整合** | ❌ **已废弃** | 实测为鸡肋：信息密度极低、与决策无关、削足适履 |

## 为什么砍掉新闻（记录决策依据）

最初设计"按估值状态反向筛选新闻"（便宜时挑悲观新闻→"这是机会"；贵时挑乐观新闻→"该警惕"），
实测后发现问题：

**优点（少）**
- 偶尔挑到真正相关的（如"公募大举调仓、软件股反弹"）
- 能让日报看起来丰富

**缺点（致命）**
1. **信息密度极低**：200 条快讯挑 2 条，与"今天该投多少"无关
2. **与决策完全无关**：定投只依赖估值分位
3. **标题党噪音**：快讯标题为吸引点击而设计
4. **模板化**：换任何新闻，解读话术都一样，新闻只是填充物
5. **削足适履**：把"美元指数上涨"硬解读成"市场乐观要警惕"——牵强附会，让事实迁就结论
6. **增加故障点**：新闻接口可能改版/限流
7. **长期必然疲劳**：每天两条无关新闻，很快会被忽略
8. **自相矛盾**：我们自己的判断是"新闻是噪声会破坏纪律"，却又每天推新闻

**核心问题**：变成了「用无关的材料，讲一遍正确的道理」——这不是信息，是说教。

## 备选方案（未采纳，留档）

- **B. 降级为按需**：不每日推，想用时手动跑
- **C. 改为事件触发**：只在真正重大事件（印花税、降准降息、证监会新政、千股跌停）时才额外提醒，
  一年约 3~5 次。理论上最优（噪声归零、价值上升），但当前选择先简化。

## 当前实现：`humanize.py`

纯确定性模板，**不调用任何大模型**，零成本零依赖。

功能：
1. 分位翻译："分位 77%" → "比过去 77% 的时间都要贵一些"
2. 按绝对分位判区域：便宜区(<40) / 中间区(40~60) / 偏贵区(>=60) / 停买区(金额=0)
3. 解释今日动作：为什么投这个金额 / 为什么不买
4. 分场景定心丸：
   - 深亏(<-15%)：浮亏不是亏损，只有卖出才变真亏
   - 小亏/持平：定投前期正常
   - 小赚：别因为赚了点就提前跑
   - 大赚(>20%)：现在最容易犯错，让规则决定
   - 停买区+盈利：策略生效，交给止盈规则
