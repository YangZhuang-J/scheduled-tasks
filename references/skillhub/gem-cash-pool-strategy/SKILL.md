# 同花顺创业板低估定投策略

对外展示名称：同花顺创业板低估定投策略。

本 skill 只运行一个已固化的策略：同花顺创业板低估定投策略（原名“创业板估值分批计划”“创业板现金池加速”）。

面向用户的简要解释：每周根据创业板的估值位置决定定投金额，低估时多投，高估时少投或分批收回；收回的资金等待下一次低估再投入。

安装流程产生 `skill_install_succeeded` 后，宿主必须自动进入 `first_activation`，不得把安装报告当作首启完成，也不得等待用户再次输入“使用/打开/介绍策略”。同一轮先用 2~4 句白话展示以下策略逻辑介绍，再介绍回测、最新信号、调整参数、查看策略详细运行逻辑四项能力，每项至少给出两条白话示例问法，最后按固定顺序展示 3 个原生按钮。这里的策略逻辑介绍是给用户看的白话说明，不要求用户先接受或确认。

> 这是一套根据创业板指近五年估值位置调整投入金额的定投策略：估值较低时多投，估值升高时逐步少投。估值处于较高区间时，策略会按规则分批赎回，资金暂存现金池；估值回落后，再将现金池资金分批投入。它固定按周执行基础定投，并可随时间逐年增加基础金额。

## 策略理念与解释

以下内容以 config/strategy.json 的 explanation 为准，所有输出必须原样包含。内容结构仅供内部编排，面向用户时不得出现“四段式”等术语：

理念：价值投资：关注估值百分位，低估时买入  
规则：创业板指五年 PE 分位决定基础申购倍数；赎回现金占比决定加速系数；分位 ≥70% 触发每日 1% 高位赎回，<70% 重置；现金按年化 1.4% 计息  
仓位/费率：按倍数分批申购，赎回资金进入现金池并加速回投；回测暂不计申购费、赎回费  
可调参数（策略，≤5）：基础申购金额、每年增幅、触发赎回分位、每日赎回比例、现金利率  
资金参数：初始资金、定期新增金额、定期新增频率（均不计入≤5，可调整）

## 策略可调参数（≤5）

当前参数值与范围：

基础申购金额=1000.0(100~10000)；每年增幅=0.07(0.0~0.2)；触发赎回分位=70.0(70~100)；每日赎回比例=0.01(0.001~0.05)；现金利率=0.014(0.0~0.05)

## 资金参数（不计入≤5，可调整）

当前参数值与范围：

初始资金=50000.0(0~1000000)；定期新增金额=5000.0(0~100000)；定期新增频率=每月(每周/每月/每季/每年)

这些资金参数不占用上述 ≤5 个策略参数名额；修改它们会改变累计投入、按实际投入节奏折算的年化收益率与资金不足买入情况。

按策略规范 v0.29 §5.4，每次回测、最新信号、基金推荐或交易计划信号计算前，先检查本地缓存的最新数据日期。缓存覆盖最近一个已结束工作日时直接复用；若缓存落后，指标和指数按缺失日期增量请求，基金净值按接口支持的区间刷新后与原缓存合并去重。回测和信号不使用当天尚未收盘的数据；缓存属于运行时产物，不随安装包分发。

### 3. 创建与到期执行

用户点击确认并设置计划后，使用平台实际支持的定时能力创建一份包含申购、赎回规则的统一计划，并立即回读结果。该计划必须有真实计划标识、状态、参数版本、时区和下次判断时间（交易日 14:30）；不得仅输出文字计划就称为已设置。

创建前检查同一用户和策略的既有统一计划；已有时更新已确认的计划，避免重复创建。创建失败或结果不明时先查询再说明，不盲目重复创建。

计划到期时：

1. 每个交易日 14:30 使用已确认的参数快照和前一交易日的有效 PE 分位计算本次申购、赎回信号与实际金额或份额。
2. 不满足触发条件时记录“本次跳过”，不提交交易。
3. 满足条件时展示本次标的、方向、实际金额或份额，以及交易 skill 所需的风险、协议、支付等信息。
4. 使用原生按钮“确认本次申购”或“确认本次赎回”与“跳过本次”。只有用户确认后，才路由至交易 skill 完成其剩余确认并提交。
5. 用户未回复、拒绝，或确认已过有效交易时段，均不提交；数据、标的、金额或份额发生变化时重新计算并重新确认。

计划创建确认不能替代交易 skill 的逐笔风险、协议、支付和最终确认。禁止自动提交、禁止用其他任务或接口绕过交易 skill 确认流程。

## 基金推荐（按需触发）

只有用户明确提出“推荐基金”“选一只跟踪基金”等请求时才触发。本 skill 先结合同花顺创业板低估定投策略的投资对象、估值定投逻辑、每周执行频率和预期持有周期，再结合用户已知的风险等级、持有期限、目标金额、费用敏感度、A/C 份额偏好、流动性需求和排除条件进行匹配；缺少会明显影响结果的信息时，只补问必要的 1~2 个问题，不擅自假定用户偏好。

- 仅使用同花顺金融数据API数据核验基金名称、代码、类型、跟踪对象、A/C 份额、可申购状态、成立日期、净值完整性、风险等级、历史回撤、波动程度和费用；数据缺失时明确标注，不用未经核验的首选基金。
- 创业板低估定投通常适合较长期、低频持续投入，默认优先比较 A 类；若用户预期持有较短、费用结构更适合 C 类，必须说明实际申购费、销售服务费和持有期差异，不能把 A/C 规则当成绝对结论。
- 中低风险用户优先展示回撤和波动相对较小、风险等级不高于用户承受范围的候选；若策略本身与用户风险承受能力不匹配，直接说明不匹配，不通过换基金掩盖风险。
- 一次给出 1~3 个按匹配度排序的候选，逐项展示：基金名称与代码、A/C 份额、跟踪对象、风险等级、历史最大回撤、波动程度、申购/赎回/销售服务费、数据日期、推荐理由和主要风险。
- 推荐结果仅是“待确认标的”，不自动修改策略参数、回测基准、交易计划或发起申购/赎回。用户明确确认后，才可将所选基金带入重新回测或交易计划参数卡；交易仍按统一计划和逐笔确认流程执行。
