# 当日买卖信号

## 命令

```bash
python scripts/cash_pool_backtest.py --config config/strategy.json --out-dir reports
```

## 输出约定

- 输出最新一周信号：数据日期、PE 分位、基础倍数、最终倍数、动作及计划买入金额；没有计划买入时显示暂停。
- 先用通俗语言概括策略如何判断估值和投入，再输出最新一周信号。
- 说明这是基于最新数据计算的目标动作，不是收益承诺。
- 解释中同时展示资金参数（初始资金、定期新增金额/频率），说明这些资金参数可调整。
- 本 skill 不生成下单命令。
- 信号必须标注数据日期，并说明为基于该日期数据计算的参考信号，不得称为实时信号。
