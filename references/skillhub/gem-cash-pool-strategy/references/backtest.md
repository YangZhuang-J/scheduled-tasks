# 回测

本 skill 只回测一个已固化策略：同花顺创业板低估定投策略。

## 命令

```bash
python scripts/cash_pool_backtest.py --config config/strategy.json --out-dir reports
python scripts/cash_pool_backtest.py --config config/strategy.json --out-dir reports/custom
```

## 结果解读

- 先用通俗语言说明策略如何判断估值、投入与现金池，再输出指标、现金池明细与买卖记录 CSV。
- 图包含策略收益曲线、基准（买入持有）曲线、买入红点/卖出绿点与回撤子图。
- 通用底线指标为回测区间、买入持有基准对比与最大回撤。
- 本策略指标集为策略时间加权收益率、基准收益率、比一直持有多赚/少赚的百分点、按实际投入节奏折算的年化收益率、累计投入、期末资产、累计盈利、新增资金次数、平均/期末赎回现金占比、申购/赎回/加速周数、资金不足买入周数及资金缺口合计。
- 买入持有基准以回测区间内同一基金复权净值归一化计算；策略时间加权收益率剔除外部新增资金影响，二者差值用“比一直持有多赚/少赚 X 个百分点”表达。
- 回测暂不计申购费、赎回费，解读结果时必须说明这一口径。
- 每次回测前检查本地缓存最新日期；若未覆盖最近一个已结束工作日，则自动从同花顺金融数据API补取缺失日期并合并缓存（基金净值按接口支持的区间刷新），缓存新鲜时直接复用。

## 展示要求

1. 先给结论，再给指标明细；所有数字须附单位和白话解释。
2. 给出通俗的策略运行说明、回测区间、买入持有基准对比、最大回撤和本策略完整指标集。
3. 给出图路径与买卖记录 CSV 路径；即使没有交易，仍生成带表头的 `trades.csv`。
4. 原样包含以下固定风险提示：

> 历史回测结果基于历史数据与既定规则模拟，不代表未来收益；市场有风险，投资需谨慎。本 skill 输出仅为决策参考，不构成投资建议。
