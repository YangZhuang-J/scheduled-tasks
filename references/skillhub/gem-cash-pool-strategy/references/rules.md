# 策略规则

## 基础申购倍数（创业板指五年 PE 分位）

| 分位 | 倍数 |
|---|---|
| ≤20% | 3.5x |
| 20%–30% | 2.5x |
| 30%–45% | 1x |
| 45%–65% | 0.5x |
| 65%–70% | 0.25x |
| >70% | 0x |

## 赎回现金池加速系数

| 赎回现金占组合资产 | 系数 |
|---|---|
| ≤10% | 1x |
| 10%–15% | 1.25x |
| 15%–20% | 1.5x |
| 20%–30% | 2x |
| >30% | 2.5x |

最终申购倍数 = 基础申购倍数 × 加速系数，并受估值区间上限约束。

## 最终倍数上限

| 分位 | 上限 |
|---|---|
| ≤20% | 6x |
| 20%–30% | 5x |
| 30%–45% | 3x |
| 45%–65% | 1.5x |
| 65%–80% | 0.5x |
| >80% | 0x |

## 高位赎回

- 分位 ≥70% 触发赎回，以首次触发时持有份额的 1% 作为每日基准赎回份额。
- 分位 <70% 后重置。
- 赎回所得进入现金池，按年化 1.4% 计息。
- 赎回现金占比 >15% 且分位处于 70%–80% 时，允许最低 0.15x 回投；分位 >80% 暂停使用赎回资金。

## 外部新增资金

- `初始资金`：回测开始一次性注入的现金。
- `定期新增金额`：按 `定期新增频率`（每周/每月/每季/每年）在周期边界注入，金额随 `每年增幅` 逐年增长。
- 新增资金计入累计投入与按实际投入节奏折算的年化收益计算；初始资金与定期新增金额/频率均不计入 ≤5 个策略参数，可自然语言调整。

## 数据与费率口径

- 行情、基金净值与指标数据仅来自同花顺金融数据API；数据缺失时明确报错，不切换其他数据源。
- 回测暂不计申购费、赎回费，交易明细中的费率按 0 记录。

## 交易计划映射

- 创建一份“同花顺创业板低估定投策略”统一计划，申购与赎回规则共用同一计划标识和管理入口。
- 统一计划固定在每个交易日 14:30（Asia/Shanghai）判断，使用前一交易日的有效 PE 分位；不让用户选择 09:30、13:00、15:00 等盘中时点。
- 申购按本策略的每周规则判断；满足时以 PE 分位、基础申购金额、现金池加速系数和最终倍数上限计算实际申购金额。赎回在同次判断中检查，满足触发赎回分位时按每日赎回比例计算本次赎回份额。
- 每次计划满足执行条件后，必须展示实际金额或份额，由用户确认后才提交；无信号、用户跳过或未确认时不提交。

## 基金推荐（按需触发）

- 只有用户明确提出推荐基金时才运行推荐；使用同花顺金融数据API 核验候选基金名称、代码、跟踪对象、A/C 份额、风险、回撤、波动、费用和数据日期。
- 本策略通常长期、低频定投，默认优先比较 A 类；若用户持有期较短或费用结构更适合 C 类，说明实际费用差异后再推荐。
- 推荐 1~3 个与创业板指数和本策略逻辑匹配的候选，不自动替换标的、修改计划或发起交易；用户明确确认后才可回测或带入统一交易计划。
