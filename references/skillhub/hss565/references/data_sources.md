# 估值数据源说明

本文件详细说明各估值数据源的适用场景、字段映射、抓取要点与注意事项。

## 一、内置 MCP 工具（优先使用）

### 1. westock-data（腾讯自选股结构化数据）

**适用场景**：A 股、港股、美股指数与基金的行情、估值、财务数据。

**主要能力**：
- 指数行情与估值（PE/PB/股息率）
- 基金净值、规模、折溢价
- 财报、研报、公告
- 宏观经济数据

**使用要点**：
- 查询指数估值：先确认指数代码，按代码查询。
- 港股指数用 HSI / HSCEI / HSTECH 等代码。
- 美股指数用 SPX / NDX 等代码。
- 若返回数据不含分位，需结合第三方源补充。

### 2. westock-tool（选股/选基工具）

**适用场景**：批量筛选低估值指数基金、同类比较。

**主要能力**：
- filter：自定义条件筛选
- strategy：预置策略（高股息、低估值等）
- 标签筛选、事件筛选、排行

**使用要点**：
- 用户问"哪些指数基金低估"时使用。
- 比较同类基金费率、规模、跟踪误差时使用。

### 3. wb-finance-skill（金融场景总入口）

**适用场景**：金融场景总入口，补充基金层信息。

**主要能力**：
- 基金净值、规模、费率
- 持仓明细、业绩归因
- 估值数据查询

### 4. neodata-financial-search（自然语言金融数据搜索）

**适用场景**：自然语言查询金融数据，补充能力。

## 二、第三方估值网站（补充使用）

当内置工具未提供完整估值分位数据时，使用以下网站抓取。

### 1. 中证指数官网（csindex.com.cn）

**URL**：`https://csindex.com.cn/#/indices/family/detail?indexCode=<指数代码>`

**适用**：A 股中证系列指数官方估值。

**可获取字段**：
- 滚动市盈率 PE-TTM
- 市净率 PB
- 股息率
- 历史分位（近1/3/5/10年）
- 成分股权重

**WebFetch prompt 示例**：
```
提取以下字段：当前PE-TTM、当前PB、当前股息率、近5年PE分位、近5年PB分位、数据日期。仅返回数值，按字段名=值格式列出。
```

**注意事项**：
- 页面为单页应用（SPA），WebFetch 可能需等待渲染。
- 部分指数估值每日收盘后更新，盘中数据可能为前一交易日。
- 中证系列代码以 `000` 或 `930` 开头。

### 2. 国证指数（cnindex.com.cn）

**URL**：`https://www.cnindex.com.cn/index.html`

**适用**：深交所系列指数（创业板指、国证系列）。

**可获取字段**：
- PE / PB / 股息率
- 成分股列表

### 3. 且慢（qieman.com）

**URL**：`https://qieman.com/index-valuation`

**适用**：A 股主流指数估值分位，每日更新，免费。

**可获取字段**：
- 当前 PE
- 历史分位（近5年/10年）
- 估值状态（低估/适中/高估）
- 颜色标识

**特点**：
- 数据简洁直观，适合快速判断。
- 覆盖主流宽基和部分行业指数。
- 不含基金层信息。

### 4. 理杏仁（lixinger.com）

**URL**：`https://www.lixinger.com`

**适用**：全市场指数历史估值分位，最全最专业。

**可获取字段**：
- PE / PB / PS / 股息率
- 多种分位区间（1/3/5/10年/全历史）
- 自定义区间分位
- ROE、增速等基本面数据

**注意事项**：
- 部分功能需登录。
- 高级功能需付费会员。
- 数据质量高，推荐作为权威源。

### 5. 天天基金（fund.eastmoney.com）

**URL**：
- 基金详情：`https://fund.eastmoney.com/<基金代码>.html`
- ETF行情：`https://quote.eastmoney.com/concept/sz<基金代码>.html`

**适用**：基金层信息（净值、规模、费率、折溢价、跟踪误差）。

**可获取字段**：
- 单位净值、累计净值
- 基金规模、份额
- 管理费、托管费
- ETF 折溢价率
- 跟踪误差
- 基金经理、成立日期
- 持仓明细

**WebFetch prompt 示例**：
```
提取以下字段：基金简称、基金类型、单位净值、累计净值、净值日期、基金规模、管理费率、托管费率、跟踪误差、成立日期。按 字段名=值 格式返回。
```

### 6. 集思录（jisilu.cn）

**URL**：
- QDII：`https://www.jisilu.cn/data/qdii/#qdiia`
- LOF：`https://www.jisilu.cn/data/lof/index.html`
- ETF：`https://www.jisilu.cn/data/etf/index.html`

**适用**：LOF/ETF 折溢价数据，QDII 溢价监控。

**特点**：
- 实时折溢价数据。
- QDII 溢价监控最权威。
- 部分数据需登录。

### 7. 长投（wo1573.com）

**URL**：`https://www.wo1573.com/Index/IndexValuation/IndexValuation2`

**适用**：简明指数估值色块图。

**特点**：
- 色块可视化直观。
- 适合快速浏览全市场估值。

### 8. 蛋卷基金（danjuanfunds.com）

**URL**：`https://danjuanfunds.com/djapi/index_eva/dj`

**适用**：指数估值列表 API。

**特点**：
- 返回 JSON 格式数据。
- 包含 PE/PB/股息率/分位/估值状态。
- 适合脚本化抓取。

## 三、数据源选择策略

### 按需求选择

| 需求 | 首选源 | 备选源 |
|------|-------|-------|
| A股指数估值分位 | westock-data | 且慢、理杏仁 |
| A股指数官方估值 | 中证指数官网 | 国证指数 |
| 港股指数估值 | westock-data | 理杏仁 |
| 美股指数估值 | westock-data | 理杏仁 |
| 基金净值/规模/费率 | wb-finance-skill | 天天基金 |
| ETF折溢价 | westock-data | 集思录 |
| QDII溢价监控 | 集思录 | 天天基金 |
| 同类比较 | westock-tool | 理杏仁 |
| 全市场扫描 | 且慢 | 长投 |

### 抓取优先级

1. 内置 MCP 工具（结构化、稳定）
2. 中证指数官网 / 国证指数（官方权威）
3. 且慢 / 蛋卷（简洁、API 友好）
4. 理杏仁（最全但可能需登录）
5. 天天基金 / 集思录（基金层信息）

## 四、数据抓取注意事项

### 1. WebFetch 使用要点

- prompt 明确指定要提取的字段名。
- 复杂页面可分多次抓取不同部分。
- SPA 页面可能需等待渲染，若返回空数据，尝试其他源。
- 若页面需登录，改用其他源或告知用户数据不可得。

### 2. 数据时效性

- A 股估值：收盘后更新，盘中通常为前一交易日数据。
- 港股估值：收盘后更新，滞后约4小时。
- 美股估值：收盘后更新，A 股时间次日上午可见。
- 基金净值：当日晚上 20:00 后更新。
- ETF 折溢价：盘中实时，收盘后定格。

### 3. 数据校验

- 多源交叉验证：关键数据用2个源核对。
- 异常值排查：PE 突变 >50% 需警惕样本调整或数据错误。
- 日期核对：确认数据日期是否为最新交易日。

### 4. 合规与频率

- 抓取频率适度，避免高频请求。
- 仅用于个人参考，不商业使用。
- 遵守各网站 robots.txt 与服务条款。

## 五、数据缺失处理

若所有数据源都无法获取某指数估值：

1. **告知用户**：明确说明该指数估值数据不可得。
2. **提供替代方案**：
   - 用相近指数估值参考（如某细分行业指数用大行业指数替代）。
   - 用成分股前十大重仓股的 PE/PB 估算。
   - 建议用户访问理杏仁等付费源。
3. **不编造数据**：宁可缺失也不杜撰。
