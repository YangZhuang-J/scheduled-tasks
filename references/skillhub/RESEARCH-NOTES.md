## 一、同花顺创业板低估定投策略 (gem-cash-pool-strategy)

- **作者**：浙江同花顺网络科技有限公司（官方）
- **标的**：创业板指 `399006.SZ` + 永赢创业板A `007664.OF`（**硬编码**）
- **估值源**：`pe_ttm_5y_pct`（5 年 PE-TTM 历史分位）
- **数据源**：同花顺金融数据 API（需 `FUYAO_API_KEY`，注册/付费，`fuyao.aicubes.cn`）
- **形态**：全流程（回测 + 当日信号 + 调参 + 基金推荐 + 交易计划）

### 官方参数表（完整固化）

**基础申购倍数（创业板 5 年 PE 分位）：**

| 分位 | 倍数 |
|---|---|
| ≤20% | 3.5x |
| 20~30% | 2.5x |
| 30~45% | 1.0x |
| 45~65% | 0.5x |
| 65~70% | 0.25x |
| >70% | 0x（停买）|

**现金池加速系数（赎回现金占组合比例）：** ≤10%→1x、10~15%→1.25x、15~20%→1.5x、20~30%→2x、>30%→2.5x

**最终倍数上限：** ≤20%→6x、20~30%→5x、30~45%→3x、45~65%→1.5x、65~80%→0.5x、>80%→0x

**高位赎回：** 分位 ≥70% 触发，首次触发时持有份额的 1%/日为基准；<70% 重置；赎回资金进现金池（年化 1.4%）；现金占比 >15% 且分位 70~80% 时允许 0.15x 回投。

**其他参数：** 每周基准 1000 元、每年增幅 7%、初始资金 5 万、每月新增 5000。

## 二、指数基金估值查询技能 (hss565)

- **作者**：个人（user_a600009d）
- **标的**：A股/港股/美股全市场指数基金（**通用，不硬编码**）
- **估值分位标准（5 档，只给方向建议）：**

| 分位 | 状态 | 建议 |
|---|---|---|
| 0~20% | 极度低估 | 定投/加仓 |
| 20~40% | 低估 | 定投/持有 |
| 40~60% | 适中 | 持有 |
| 60~80% | 高估 | 减仓/止盈 |
| 80~100% | 极度高估 | 回避/清仓 |

- **形态**：仅诊断（查估值 → 判分位 → 报告 → 方向建议），无倍数/金额/回测/交易计划
