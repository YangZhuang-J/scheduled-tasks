# 第 0 步：回测验证想法

## 目标

用真实历史数据回答一个问题：**「按估值分位定投」是否真的优于「无脑定投」？**

- 无脑定投：固定周期、固定金额，风雨无阻
- 估值分位定投：低估加倍、高估放缓/停买、高位分批止盈

## 标的

| 标的 | 数据源 | 估值指标 | 备注 |
|---|---|---|---|
| 沪深 300 | akshare（中证/乐咕乐股） | PE/PB 历史分位 | 估值数据最易得 |
| 纳指 100 | akshare（东财全球指数） | PE 历史 | 美股 PE 历史数据较难免费获取 |
| 标普 500 | akshare（东财全球指数） | PE 历史 | 同上 |

## 做法

1. 拉取指数历史收盘价 + 历史估值（PE）序列
2. 计算 PE 历史分位（滚动窗口，如 5 年）
3. 按「温度表」映射定投倍数（第 2 步会正式定义，这里先用简化版）
4. 回测对比：无脑定投 vs 估值定投 → 总收益、年化、最大回撤
5. 输出结论：这个想法值不值得继续做

## 产物

- 数据拉取脚本
- 回测脚本 + 对比结果图表/表格
- 一份「结论备忘」
